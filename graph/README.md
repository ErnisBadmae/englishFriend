## Graph Layer

This directory hosts Sprint 5 artifacts for the Neo4j/Memgraph layer: schema constraints, ingest scripts, queries, and operational documentation.

### Structure
- `schema/` — Cypher files for constraints, indexes, and reference data priming.
- `queries/` — Saved Cypher queries for recommendations, analytics, and debugging.
- `docs/` — Runbooks, integration guides, and config examples.
- `tests/` — Automated checks (cypher-shell scripts) for schema validation.

Refer to `graph/docs/RUNBOOK.md` for setup instructions and testing guidance.
